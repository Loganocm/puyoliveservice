## What this is

Puyo Live is a competitive, browser-based falling-block puzzle game in the
Puyo tradition: real-time 1v1 multiplayer, deterministic replays, ratings and
player profiles, plus a free-for-all mode (Puyo Mines). It runs as three
services around one shared, deterministic simulation package.

This site is the single source of truth for how it works and where it is going.
Every pull request that changes behaviour updates the relevant page here, and CI
refuses the change if it does not ([how that works](/start/documentation-system/)).
